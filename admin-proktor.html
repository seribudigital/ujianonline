Manajemen Arsip Ujian

Alur Kerja Ganti Sesi Baru (Mata Pelajaran Baru)

Jika sesi ujian mapel saat ini sudah selesai, cukup klik Tutup Sesi Ujian (Tombol Merah) agar gerbang login terkunci untuk gelombang/siswa baru.

Anda bisa langsung mengunggah file JSON soal baru untuk mata pelajaran berikutnya. Data ujian mapel sebelumnya aman tersimpan di cloud Supabase sebagai log history dan tidak akan bercampur. Anda tetap bisa melihat dan mencetaknya kapan saja melalui fitur manajemen arsip.

Catatan: Tombol Hapus Permanen dari Cloud dan Download Arsip JSON hanya digunakan di akhir semester atau akhir tahun ajaran saat database ingin dikosongkan total untuk angkatan baru.
